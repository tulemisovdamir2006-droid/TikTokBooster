# TikTok Booster

Безопасная Android-утилита для диагностики устройства и быстрого перехода к настройкам TikTok.

## Что умеет
- Показывает доступную RAM и свободное место во внутреннем хранилище.
- Проверяет системный флаг нехватки памяти.
- Открывает системную карточку приложения TikTok.
- Открывает системные настройки оптимизации батареи.
- Запускает TikTok.

## Чего приложение намеренно не делает
Android не предоставляет обычным сторонним приложениям право очищать кэш или завершать процессы другого приложения напрямую. Поэтому здесь нет фиктивной кнопки «ускорить на 300%», скрытых сервисов, root-доступа или сбора данных. В карточке TikTok можно открыть раздел хранилища и очистить только кэш. Не выбирайте «Очистить данные», если не хотите сбросить приложение.

## Сборка APK
1. Установите Android Studio (версия с поддержкой Android Gradle Plugin 8.6.1).
2. Откройте папку `TikTokBooster` как проект.
3. Дождитесь синхронизации Gradle и установки Android SDK 35.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Минимальная версия Android: 6.0 (API 23). Проект не запрашивает опасных разрешений и не отправляет данные в интернет.

## Сборка APK без компьютера (через GitHub)

1. На телефоне откройте https://github.com/ и войдите или создайте аккаунт.
2. Нажмите **+** → **New repository**. Назовите репозиторий `TikTokBooster`, выберите **Public** или **Private**, затем создайте его.
3. На странице репозитория нажмите **Add file** → **Upload files**.
4. Распакуйте ZIP проекта на телефоне и загрузите всё содержимое папки `TikTokBooster` в корень репозитория. Важно: вместе с файлами должна загрузиться скрытая папка `.github` и файл `.github/workflows/build-apk.yml`. Если файловый менеджер скрывает папки с точкой, включите показ скрытых файлов.
5. Нажмите **Commit changes**.
6. Откройте вкладку **Actions**. Дождитесь завершения задания **Build TikTok Booster APK** со статусом зелёной галочки.
7. Откройте завершённый запуск и внизу раздел **Artifacts**. Скачайте `TikTokBooster-debug-apk`, распакуйте скачанный ZIP и установите `app-debug.apk`.

Если GitHub не запускает сборку автоматически, откройте **Actions** → **Build TikTok Booster APK** → **Run workflow**.
